## 💻 Running It Locally

Want to see it in action? Here's how:

```bash
# Navigate to the project directory
cd react-portfolio/

# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The dev server will start on port 5173 (or the next available port if that's taken).

## 🎨 Architecture Highlights

**Image Sequence Animation:**
- 301 frames in `/public/frames/` create a video-like scroll effect
- Canvas-based rendering for smooth performance
- Frame extraction tool included (`frame-extractor.html`)

**Component Structure:**
- Self-contained animation components
- Intersection Observer for scroll-triggered effects
- GSAP for complex scroll animations
- Framer Motion for component-level interactions

**Navigation System:**
- Gooey morphing navigation with smooth transitions
- Hash-based routing for section navigation
- Sticky positioning with dynamic active states
